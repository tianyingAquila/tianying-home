# Tianying的巢

一个个人网站首页，包含：

- 个人简介与社交链接
- 首页固定音乐播放器（支持多首歌曲切换）
- 可编辑随笔
- 留言板（每条最长 20 字，最多保留 5 条）
- 图片集轮播
- 项目卡片
- 日间 / 夜间模式
- 系统运行时间和当前时间

## 技术栈

- 前端：原生 HTML / CSS / JavaScript，无构建步骤
- 后端：PHP 单文件 API（`api.php`），数据存为 JSON 文件
- 无需数据库

## 目录结构

```
├── index.html          # 首页
├── admin.php           # 网站管理后台
├── api.php             # 接口
├── config.php          # 公共配置
├── assets/             # 样式、脚本、图片、音乐
├── data/               # 网站内容和留言数据
└── uploads/            # 后台上传的图片
```

网站的文字、链接、图片集、项目等内容都可以在管理后台中修改，改完刷新首页即可生效。
