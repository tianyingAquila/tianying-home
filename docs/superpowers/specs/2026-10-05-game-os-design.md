选择页改为浅色平面程序选择器：当前方形透明模块、右侧缩小但露出大半的下一模块、始终对齐中央模块的底部插槽。选择器的尺寸和对齐来自统一 CSS 变量；切换只使用平移、缩放、透明度。使用既有系统无衬线字、等宽编号，#f2f0ec 奶白、#14161a 墨黑、#e7e4df 机身灰、#7060a8 状态紫。保留主导航、游戏名、编号、类型、数量、时间、简介和站点署名。

每个卡带包含对应原游戏页面的同源 iframe；预览裁切并缩放真实 DOM 棋盘或真实 Canvas。启动不换文档、不替换棋盘：320ms 下插、1180ms 展开、250ms 完成，总计 1750ms。框体变为游戏界面边界，预览窗口展为完整运行区，原标签变为程序状态。加载进度在底部插槽显示。退出 850ms 反向收拢，保留游戏实例和进度。选择器期间暂停塔防推进、暂停扫雷计时；运行时恢复。不更改冻结塔防版本或规则。

用 query 参数隔离嵌入样式，独立游戏页继续正常访问。原生 CSS / Web Animations，无新增依赖。减少动态效果设置跳过空间动画。至少验证 1440、1280、1024 桌面宽度，并检查窄屏。验证真实开格、插旗、提示、配置、建造、开波、暂停、地图选择以及退出后恢复；检查棋盘 / Canvas 节点身份和页面 URL 在启动前后保持一致。执行全套 Node 回归、冻结版本验证和 diff 检查；更新 README。
